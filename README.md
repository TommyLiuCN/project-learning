# project-learning

A collection of personal hands-on learning projects for several programming languages, each organized as a separate top-level folder.

| Folder        | Language | Highlights                                              |
|---------------|----------|---------------------------------------------------------|
| `golearning`  | Go       | goroutines, channels, interfaces, generics, file/JSON   |
| `javalearning`| Java     | OOP, collections, generics, exceptions, lambda/stream   |
| `rustlearning`| Rust     | ownership, traits, lifetimes, smart pointers, concurrency |
| `pylearning`  | Python   | syntax, data types, OOP, decorators, file/OS, stdlib    |

Each folder is self-contained with its own README and code organized by lessons.

## Structure

```
project-learning/
├── golearning/     # Go learning project
├── javalearning/   # Java learning project
├── rustlearning/   # Rust learning project (Cargo)
└── pylearning/     # Python learning project
```
